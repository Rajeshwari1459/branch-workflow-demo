- Create a new repo on GitHub (e.g., branch-workflow-demo).
- Change directory in terminal where repo has to be cloned
- Clone it locally:
  bash
  git clone https://github.com/<your-username>/branch-workflow-demo.git
- cd branch-workflow-demo
- git checkout -b feature/navbar-branch creation → You make a new branch for a feature,bug fix,orexperiment.
- Development on that branch → You commit changes only in that branch, keeping main clean.
- Push branch to remote → Share your branch on GitHub so others can see or collaborate.
- Pull request (PR) → Propose merging your branch into another branch (often develop or main).
- Code review & merge → Team members review changes, then merge them into the target branch.
- Delete branch (optional) → Once merged, you can delete the feature branch to keep the repo tidy.
